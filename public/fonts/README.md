# Fontes locais

Este diretório contém os subconjuntos `latin` e `latin-ext` usados pelo site:

- Geist
- Montserrat

Os arquivos foram gerados pelo `next/font/google` a partir das fontes distribuídas pelo Google Fonts e são hospedados localmente para evitar dependência de rede durante o build e na navegação. Ambas são distribuídas sob a SIL Open Font License 1.1.
